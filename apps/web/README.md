# @clinara/web

Next.js (App Router) frontend for admin, authoring, and clinician surfaces. SSR for
administration; accessibility-first components (spec §7.2, §6.10, §6.11).

```bash
npm install
npm run dev   # http://localhost:3000
```

Phase 0 ships only a placeholder shell. The clinician inbox (Phase 1), Rule Studio
(Phase 2), and dashboards (Phase 6) build on top of it.
